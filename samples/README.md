# Public sample logs

`demo.mlg` is the bundled startup sample for desktop and for the web when no sample is named. Capture metadata and the embedded tune are removed from this public copy, so tune based table overlays and firmware verified derived error channels are unavailable for it. Its numeric `Gwarm` channel appears under its original name in the default CLT/WUE/Fan plot group; the source label is not rewritten or treated as a verified alias.

Place intentionally public, cropped `.mlg` files in this directory. The web build copies this directory unchanged. A link uses the filename only, for example:

`?sample=example.mlg&playhead=12.5&start=10&end=20`

The times are elapsed seconds from the first recorded sample in that file. `playhead` sets the white playback line; `start` and `end` set the blue range handles. Either range endpoint may be omitted. The range includes recorded samples on both boundaries.

Do not add private captures or logs that you do not have permission to publish.
